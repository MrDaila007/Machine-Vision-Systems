# Практика 2. Частотная фильтрация

Два кадра.

`sample6.jpg` — мелкие тёмные точки. Растровая фильтрация — морфологическое закрытие эллипсом 15×15. Отдельно гауссов фильтр низких частот через БПФ, затем оба шага подряд.

`sample1.jpg` — периодические наклонные полосы. В формулировке задания помеха названа горизонтальной, на этом файле полосы идут по диагонали. Режекторный фильтр находит самый яркий пик спектра вне осей и гасит прямую гармоник, проходящую через него.

Код и PDF называются `Eliseev D`. Имя задаёт константа `SURNAME` в `Eliseev D.py`.

## Данные

- `data/sample6.jpg`
- `data/sample1.jpg`

## Запуск

```bash
conda activate mvs
python "Eliseev D.py"
```

## Результат

Кадры стадий лежат в `output/`. Отчёт — `Eliseev D.pdf` в этой папке.
