# Практика 8. Анализ видео

Ролик живой клетки `MKCell.mp4` (1920×1080, 30 кадр/с, около 150 с). Подвижные частицы — красные точки на синем теле клетки. Кадр уменьшается вдвое. Детектор оставляет локальные максимумы красного канала внутри тела клетки: тонкие выросты срезает морфологическое открытие, порог яркости подстраивается под выцветание красителя.

Точки связываются между кадрами по ближайшему центру (венгерский алгоритм, порог 14 пикселей). Пропуск до 12 кадров трек не обрывает. В статистику входят треки длиннее 15 точек.

## Данные

- `data/MKCell.mp4`

## Запуск

```bash
conda activate mvs
python track_particles.py
```

Полный ролик обрабатывается несколько минут.

## Результат

- `output/tracked.mp4` — треки поверх кадра
- `output/preview.jpg` — несколько кадров полосой
- `output/stats.txt` — число треков и скорость обработки в кадрах в секунду
