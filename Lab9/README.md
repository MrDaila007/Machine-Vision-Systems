# Практика 9. Свой трекер на оптическом потоке

Тот же ролик, что в практике 8. Детектор частиц тот же, но положение между кадрами переносится оптическим потоком Лукаса–Канаде по красному каналу, а не повторным сопоставлением центров. Каждые 10 кадров в трекер добавляются новые детекции, если рядом нет уже ведомой точки. Скачок больше 18 пикселей за кадр отбрасывается.

Сравнение с Lab8 лежит в `output/stats.txt`, если статистика восьмой практики уже посчитана. Имеет смысл сначала запустить Lab8.

## Данные

- `data/MKCell.mp4`

## Запуск

```bash
conda activate mvs
python optical_flow_tracker.py
```

## Результат

`output/flow_tracked.mp4`, `output/preview.jpg`, `output/stats.txt`.
