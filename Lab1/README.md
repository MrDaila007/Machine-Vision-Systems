# Практика 1. Корреляционный фильтр

Нужно построить фильтр на основе корреляции, без готовых реализаций фильтрации. В `correlation_filter.py` функция `correlate` использует только NumPy: ядро не отражается, край кадра дополняется краевыми значениями.

Три ядра 5×5 из задания:

1. все единицы — сглаживание;
2. две верхние строки −1, средняя 0, две нижние +1 — горизонтальный перепад;
3. то же, но центральный элемент равен 1.

Нормализация: деление на сумму элементов, а если сумма равна нулю — на сумму модулей.

## Данные

- `data/boat1.jpg`
- `data/boat2.png`

## Запуск

```bash
conda activate mvs
python correlation_filter.py
```

## Результат

В `output/` для каждого кадра лежат исходник, три отклика и монтаж `*_montage.jpg`.
