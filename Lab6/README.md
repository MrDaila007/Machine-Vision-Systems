# Практика 6. Математическая морфология

## Зёрна

`sample10.jpg` бинаризуется по Оцу, открытие отделяет слипшиеся края, водораздел по локальным максимумам карты расстояний разрезает оставшиеся касания. Каждая связная область красится своим цветом. Число зёрен печатается в консоль и на `output/grains_colored.png`.

## Волокно

На `sample29_cut.jpg` тёмное волокно выделяется инверсным порогом Оцу. Длина — длина скелета в пикселях с учётом диагональных шагов. Ширина — удвоенное среднее расстояние от скелета до края маски. Физического масштаба в задании нет, обе величины в пикселях. Если волокно распалось на части, в `output/fiber_measures.txt` есть мера каждой части и сумма.

## Данные

- `data/sample10.jpg`
- `data/sample29_cut.jpg`

## Запуск

```bash
conda activate mvs
python morphology.py
```

## Результат

`output/grains_binary.png`, `output/grains_colored.png`, `output/fiber_mask.png`, `output/fiber_overlay.png`, `output/fiber_measures.txt`.
