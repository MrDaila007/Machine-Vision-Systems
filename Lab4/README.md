# Практика 4. Выделение линий

Теплоход на `boat1.jpg` выделяется прямыми: контур Кэнни и преобразование Хафа. В `output/ship_lines.jpg` красным оставлены длинные почти горизонтальные линии корпуса и палубы и короткие вертикальные линии надстройки. Полоса по высоте кадра отсекает отражение в воде. `output/all_lines.jpg` показывает все найденные отрезки.

В задании имя файла не указано. Взят `boat1.jpg`: на нём теплоход снят сбоку.

## Данные

- `data/boat1.jpg`

## Запуск

```bash
conda activate mvs
python lines.py
```

## Результат

`output/ship_lines.jpg`, `output/all_lines.jpg`, `output/edges.jpg`.
