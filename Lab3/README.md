# Практика 3. Гистограмма

На рентгенограмме `0.063-1_2.5x_View2.dcm` — сварной шов металлической пластины. Сырой диапазон яркостей шов прячет. Скрипт читает DICOM, растягивает окно по перцентилям 5% и 95% и выравнивает локальный контраст (CLAHE), чтобы стали видны шов и мелкие дефекты.

## Данные

- `data/0.063-1_2.5x_View2.dcm`

## Запуск

```bash
conda activate mvs
python histogram.py
```

## Результат

- `output/weld.jpg` — кадр для отчёта
- `output/weld_wide.jpg` — широкое окно без CLAHE
- `output/histograms.png` — гистограммы до и после
