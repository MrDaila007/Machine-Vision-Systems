# Практика 7. Характеристики объектов

На `sample30.jpg` светлые объекты отделяются порогом Оцу. Для каждого объекта с площадью не меньше 2 пикселей считаются:

- площадь;
- периметр;
- угол главной оси — `orientation` из scikit-image, в градусах от вертикали против часовой стрелки;
- длины главной и ортогональной осей.

`data/result.txt` — эталон (площадь, оси, центр, периметр, без угла). `output/summary.txt` сравнивает число объектов и то, насколько центры и площади близки к этому эталону.

## Данные

- `data/sample30.jpg`
- `data/result.txt`

## Запуск

```bash
conda activate mvs
python features.py
```

## Результат

`output/features.csv`, `output/objects.jpg` (зелёный эллипс, красный отрезок главной оси), `output/summary.txt`.
